# Definition of Done

An increment is Done only when every box is checked. "Done except…" is not Done.

- [ ] Acceptance criteria of the story are met and demonstrated
- [ ] Tests exist for new behavior and the full test suite passes
- [ ] No new linter/type errors
- [ ] No secrets, credentials or personal data committed
<!-- BEGIN:security -->
- [ ] Security-relevant changes checked against `security/SECURITY-BASELINE.md`
<!-- END:security -->
<!-- BEGIN:adr -->
- [ ] Significant decisions recorded as ADRs (`/adr-new`)
<!-- END:adr -->
<!-- BEGIN:memory -->
- [ ] Living memory updated (`/memory-update`)
<!-- END:memory -->
- [ ] Documentation touched by the change is updated
