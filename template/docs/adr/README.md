# Architecture Decision Records

Numbered, immutable records of significant decisions (MADR-lite format, see
`template.md`). Create one with `/adr-new`.

When to write an ADR: the decision is hard to reverse, affects structure or dependencies,
or someone will later ask "why is it like this?". Accepted ADRs are never edited — write a
new one that supersedes the old and update both statuses.
